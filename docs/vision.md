# Nyxdoc vision

Nyxdoc은 사람이 쓰던 문서 도구에 AI 버튼을 붙인 제품이 아니다. 사람이 평소 사용하는 외부 에이전트와 이야기하면, 그 에이전트가 읽고 쓸 수 있는 문서 시스템이다.

사람은 Codex, Claude Code, OpenClaw 같은 자신의 에이전트에게 일을 부탁한다. 에이전트는 Nyxdoc의 API 또는 MCP를 통해 필요한 문서를 찾고, 현재 리비전을 읽고, 결과를 새 리비전으로 저장한다. Nyxdoc 안에 별도의 대화형 에이전트를 두지 않는다.

## 제품 약속

> 내가 쓰는 에이전트에게 말하면 문서가 정리되고, 사람이 직접 고친 내용도 다음 에이전트가 놓치지 않는다.

대화는 의도를 전달하는 곳이고 문서는 오래 남는 상태다. 채팅 기록을 다시 해석하지 않아도 다음 사람이나 에이전트가 실제 문서와 변경 기록에서 이어서 일할 수 있어야 한다.

## 핵심 계약

### 외부 에이전트가 일한다

Nyxdoc은 모델을 선택하거나 에이전트를 실행하지 않는다. 인증된 도구 표면과 문서 상태를 제공한다. 첫 통합 대상은 Codex이며, 프로토콜은 특정 에이전트에 종속되지 않는다.

### 모든 쓰기는 같은 경로를 지난다

웹 편집, MCP, REST API는 하나의 문서 변경 서비스를 사용한다. 어떤 경로에서 바뀌어도 새 리비전과 변경 이벤트가 함께 생기며 행위자와 출처가 기록된다.

### 사람도 필요할 때 직접 고친다

웹 편집기는 예외가 아니라 정식 입력 경로다. 사람이 고친 내용은 `human/web` 리비전으로 남고, 외부 에이전트는 변경 커서로 이를 발견한다.

### 오래된 상태를 덮어쓰지 않는다

에이전트와 사람은 읽었던 기준 리비전을 함께 제출한다. 그 사이 문서가 바뀌었으면 저장을 거절하고 최신 문서를 다시 읽게 한다.

## 사람과 에이전트의 역할

사람은 의도, 판단, 관계를 맡는다. 에이전트는 맥락 탐색, 초안 작성, 반복 수정을 맡는다. Nyxdoc은 어느 쪽도 특별 취급하지 않고 결과와 이유를 같은 문서 역사에 남긴다.
