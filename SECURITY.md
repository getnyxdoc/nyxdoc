# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to `security@nyxdoc.com`.
Do not open a public issue for an unpatched vulnerability.

Include:

- the affected version or commit;
- a concise reproduction or proof of concept;
- the expected security impact; and
- any suggested mitigation.

Do not include real user documents, production databases, credentials, agent
connection keys, or personal information. Use minimal synthetic data.

The project will acknowledge and investigate reports on a best-effort basis.
There is no guaranteed response or remediation SLA. Please allow a reasonable
coordinated-disclosure period before publishing details.

## Supported versions

Security fixes target the latest published release and the current `main`
branch. Older releases may not receive backports.
